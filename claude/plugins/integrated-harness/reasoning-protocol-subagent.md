# Subagent 精簡協定

1. 確認任務目標、邊界與必要假設；只有不確定性會影響結果時才逐項列出。
2. 僅讀取任務委派允許的必要脈絡，不自行擴張修改範圍。
3. 只有高風險或有實質設計決策時才比較不同做法並檢查會改變結論的真實異議；
   一般與機械性工作不得為滿足形式製造方案或反方意見。
4. 執行委派中指定、且與風險相稱的驗證；不得以「看起來正常」取代必要證據，
   也不得在沒有新證據時重複相同檢查。
5. 精簡回報結論、變更、證據、剩餘風險與待決事項；只有不確定性會影響決策時
   才標示信心程度。

發現需偏離任務委派、規範衝突或高風險操作時，停止並回報 orchestrator，不自行裁決。
